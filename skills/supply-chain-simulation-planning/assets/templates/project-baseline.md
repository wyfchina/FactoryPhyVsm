## 3. 迭代路线与阶段特征

区分三种编号：`01–14` 是默认核心工作包编号，每个启用的工作包对应一份单独的 Markdown Issue 文件；`I1`、`I2`、`I3`……是模型逐轮丰富的迭代轮次；`.1` 至 `.7` 是每轮的默认构建/验证环节。因此 `I1.1–I1.7` 表示第一轮路线中的七个环节，`I2.1–I2.7` 表示第二轮路线中的同类环节。项目级 `01.md` 总路线必须列明每个环节由哪些 Issue 文件落实；具体 Issue 文件也要记录所属轮次和环节。迭代轮数不设上限。

### 每轮迭代的默认环节

| 子阶段编号 | 默认环节 | 本环节的主要责任 |
|---|---|---|
| `.1` | 本轮目标与增量范围 | 说明本轮相对上一轮要解决的问题、模型增量、固定控制和验收条件 |
| `.2` | 数据与机制定义 | 确认本轮所需数据、假设、机制语义和输入版本 |
| `.3` | 脆弱机制原型 | 对高风险或平台语义不确定的新增机制做最小验证；无此类机制时注明理由 |
| `.4` | 模型增量实现 | 在上一轮通过版本上实现本轮新增复杂度，记录模型和数据版本 |
| `.5` | 新增机制验证 | 用解析预期、确定性场景、边界案例或适当的随机验证检查本轮变化 |
| `.6` | 回归与状态确认 | 重跑受影响的既有验证；按用户要求将本轮状态标为基线、研究状态或普通迭代结果 |
| `.7` | 本轮评审与交接 | 汇总差异、证据、未决风险和下一轮入口；仅最后一轮承担最终项目交付 |

| 轮次环节 | 默认对应核心工作包 Issue 文件 | 项目路线中的实际文件映射 |
|---|---|---|
| `.1` 本轮目标与增量范围 | `01.md` |  |
| `.2` 数据与机制定义 | `02.md`、`03.md` |  |
| `.3` 脆弱机制原型 | `04.md`（如启用） |  |
| `.4` 模型增量实现 | `05.md`、`06.md`，也可包含专项 Issue |  |
| `.5` 新增机制验证 | `07.md`、`08.md` |  |
| `.6` 回归与状态确认 | `09.md`（如定义基线/研究状态）；回归证据写入相关 Issue |  |
| `.7` 本轮评审与交接 | `10.md`–`14.md` 中本轮适用的实验/交付 Issue |  |

上表给出默认责任映射，不要求每轮重复执行全部核心工作包。对每轮，项目路线必须标出实际使用的文件及其路径，例如 `iterations/I2/06.md`；未启用项标为 `N/A` 并说明理由。若一个环节跨多个 Issue，或一个 Issue 跨多个环节，应在两处映射中写清楚。

### 迭代轮次登记

按项目需要增加 `I4`、`I5` 等轮次，不要把表格限制在预置行数。每一轮的 `.1–.7` Issue 可各自成文，也可合并为一个文件，但项目路线表必须能定位到实际 Markdown 文件。

| 迭代轮次 | 本轮模型目标/复杂度增量 | 继承版本 | Issue 文件目录/清单 | 本轮模型/数据版本 | 本轮验收状态 | 下一轮进入条件 |
|---|---|---|---|---|---|---|
| I1 |  | 初始输入/无模型 | `iterations/I1/01.md`–`14.md`（按需启用） |  |  |  |
| I2 |  | I1 的通过版本 | `iterations/I2/01.md`–`14.md`（按需启用） |  |  |  |
| I3 |  | I2 的通过版本 | `iterations/I3/01.md`–`14.md`（按需启用） |  |  |  |
| I4+ | 按需追加 | 上一轮指定的通过版本 | 每轮各自目录，按需建立 Issue 文件 |  |  |  |

项目级 `01.md` 维护上述轮次表和每轮 `.1–.7` 环节到文件的映射。建议目录结构如下：

```text
01.md                         # 项目总路线：定义 I1、I2… 及映射
iterations/
  I1/01.md ... 14.md          # 第一轮各核心工作包的独立 Issue 文件
  I2/01.md ... 14.md          # 第二轮实际启用的工作包文件
  I3/...
```

实际路线可以合并或新增子阶段，例如在轮次目录中增加 `04a.md`、`04b.md` 分开实现两个高风险机制；也可以在某轮因某环节确实不适用而标注 `N/A` 并说明依据。迭代轮次表示模型增量循环，不代表基线、方案实验或最终交付必然发生在固定轮次。

仅完成最小结构运行时，应标为“结构原型”，不能直接标为正式基线。
